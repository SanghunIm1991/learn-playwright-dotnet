# Playwright for .NET 学習教材

この教材は、Playwright を使ったブラウザテストの自動化を、まったくの初心者が C#（NUnit）で一歩ずつ学べるように作ったものです。
題材は、このリポジトリに含まれるサンプルフォームアプリ（`src/LearnPlaywright.Server`）です。

> **注意（必ずお読みください）**
>
> - サンプルアプリは**学習用**です。認証・認可の仕組みを持たず、自分のPC（`localhost`）の中だけで動かす前提で作られています。インターネットに公開して使わないでください。
> - フォームに入力した内容は、サーバー側にJSONファイルとして保存されます。**氏名・連絡先・クレジットカード番号などの実在の個人情報や機微情報は絶対に入力せず、`ダミー太郎` のようなダミー値だけを使ってください。**

## 読み方

- **先頭から順番に読んでください。** 2章以降の各レッスンは「その章より前に出てきた内容だけ」を前提にしています。後ろの章で習う書き方（ヘルパー関数、`[TestCaseSource]`、`[SetUp]` など）は、その章に来るまで使いません。
- 各章の冒頭に「この章の前提知識」を書いています。分からない項目があれば、前の章に戻ってください。
- 0章と2章の最後まで進めば、「環境を整えて、自分で書いたテストを実行し、成功させる」ところまで到達できます。1章は考え方の解説だけで、コマンド操作はありません。
- サンプルコードのコメントには、「何をしているか」だけでなく「なぜそう書くのか」も書いています。コメントも本文の一部として読んでください。

## 2つのテストプロジェクトの違い

この教材では、次の2つを区別します。

| 名前 | 場所 | 役割 |
|---|---|---|
| 学習用プロジェクト（`MyFirstPlaywrightTests`） | リポジトリの**外**の、自分の作業フォルダ（例: `C:\work\MyFirstPlaywrightTests`） | 0章で作り、2〜9章のテストを自分の手で書いていく練習場所 |
| 本体のテストプロジェクト | リポジトリの `tests/LearnPlaywright.Tests` | このリポジトリに最初から入っている完成版のテスト。9章で読み比べます |

学習用プロジェクトを作っても、リポジトリの `tests/` 配下は変更されません。本体側のファイルは、答え合わせ用の「お手本」として読むだけにしてください。

## サーバーの起動について

- 2〜7章では、テストを実行する前に、**別のターミナルでサンプルアプリのサーバーを手動で起動**しておきます（リポジトリのルートフォルダで `dotnet run --project src/LearnPlaywright.Server`）。
- 8章以降は、テストコード自身がサーバーを自動で起動するようになるため、手動起動は不要になります（8章で詳しく案内します）。

## 用語の早見表

| 用語 | 意味 |
|---|---|
| Playwright | ブラウザ（Chromium など）をプログラムから操作するためのライブラリ |
| NUnit | C# のテストフレームワーク。`[Test]` などの属性でテストを書く |
| ロケーター | 画面上の要素（入力欄やボタン）を探すための「目印」 |
| `data-testid` | テストから要素を探すために、HTMLに付けておく専用の属性 |
